# 🔐 Zip-Cracker 🔐

یک ابزار قدرتمند برای کرک پسورد فایل‌های ZIP با استفاده از لیست کلمات

![Version](https://img.shields.io/badge/version-1.2-blue)
![Python](https://img.shields.io/badge/Python-3.6%2B-green)

## 🚀 ویژگی‌ها

- 🔍 پشتیبانی از فایل‌های ZIP با رمزنگاری AES
- 📝 استفاده از لیست کلمات برای کرک پسورد
- 🎨 رابط کاربری رنگی و جذاب
- ⚡ سرعت بالا در کرک پسورد
- 📊 نمایش پیشرفت عملیات
- 🎯 پشتیبانی از فایل‌های بزرگ

## 📋 پیش‌نیازها

- Python 3.6 یا بالاتر
- کتابخانه‌های مورد نیاز:
  ```
  pyzipper
  colorama
  ```

## 🔧 نصب

1. ابتدا مخزن را کلون کنید:
   ```bash
   git clone https://github.com/minyhacktelegram/zipcracker.git
   ```

2. به دایرکتوری پروژه بروید:
   ```bash
   cd zipcracker
   ```

3. کتابخانه‌های مورد نیاز را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```

## 💻 نحوه استفاده

1. برنامه را اجرا کنید:
   ```bash
   python Zip-Cracker.py
   ```

2. مسیر فایل ZIP را وارد کنید
3. مسیر فایل لیست کلمات را وارد کنید
4. منتظر بمانید تا برنامه پسورد را پیدا کند

## 📝 مثال

```
[*] Enter ZIP file path: example.zip
[*] Enter password list path: passwords.txt

```
